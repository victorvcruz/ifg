# DOCUMENTO 1 – VISÃO DO PRODUTO

## 1. Introdução
> Descreva brevemente o sistema que será desenvolvido, explicando a ideia geral e o contexto de uso.
Resposta:

Será desenvolvido um sistema para Cadastro de Clientes, voltado a um pequeno empresário que atualmente gerencia seus clientes de forma manual. O sistema tem como objetivo digitalizar o processo de cadastro e gerenciamento de clientes, proporcionando uma solução mais eficiente e organizada.

## 2. Objetivo do Sistema
> Explique o principal objetivo do sistema.
Resposta:

O principal objetivo do sistema é fornecer uma plataforma para armazenar e gerenciar informações de clientes, facilitando o acesso, a organização e a análise dos dados, além de melhorar a eficiência no atendimento ao cliente.

## 3. Problema que o Sistema Resolve
> Descreva os problemas atuais que o sistema irá solucionar.
Resposta:

O sistema irá resolver os seguintes problemas:
- Dificuldade em localizar informações rapidamente
- Risco de perda ou dano aos registros manuais
- Impossibilidade de gerar relatórios
- Dificuldade em identificar padrões e histórico de clientes

## 4. Usuários do Sistema
> Indique quem utilizará o sistema.
Resposta:

Os usuários do sistema serão o empresário e os funcionários do negócio, que terão acesso para cadastrar, consultar e gerenciar as informações dos clientes.

# 5. Principais Funcionalidades
> Liste as principais funcionalidades do sistema.
Resposta:

- Cadastro de clientes
- Consulta de clientes
- Edição de informações de clientes
- Geração de relatórios de clientes
- Busca por clientes
- Armazenamento seguro dos dados

## 6. Benefícios do Sistema
> Descreva os benefícios esperados com a implantação do sistema.
Resposta:

- Melhor organização dos dados
- Maior rapidez no atendimento
- Redução de erros de registro
- Facilidade de acesso às informações
- Capacidade de gerar relatórios e análises de clientes

# DOCUMENTO 2 – ESCOPO DO PROJETO

## 1. Descrição do Produto
> Explique o que é o sistema e para que ele será utilizado.
Resposta:

O sistema de Cadastro de Clientes é uma aplicação digital que permitirá ao empresário e seus funcionários cadastrar, consultar e gerenciar informações dos clientes de forma eficiente. O sistema será utilizado para organizar os dados dos clientes, facilitar o acesso às informações e melhorar a eficiência no atendimento.


## 2. Objetivo do Projeto
> Descreva o objetivo do projeto.
Resposta:

O objetivo do projeto é desenvolver um sistema de informação para cadastro de clientes que atenda às necessidades do pequeno empresário, proporcionando uma solução digital para o gerenciamento eficiente dos dados dos clientes.

## 3. Funcionalidades Incluídas no Escopo
> Liste as funcionalidades que serão desenvolvidas.
Resposta:

As principais funcionalidadees incluídas no escopo:
- Cadastro de clientes
- Consulta de clientes
- Edição de informações de clientes
- Geração de relatórios de clientes
- Busca por clientes
- Armazenamento seguro dos dados

## 4. Funcionalidades Fora do Escopo
> Liste funcionalidades que não serão desenvolvidas nesta versão.
Resposta:

- Integração com sistemas de pagamento
- Funcionalidades de marketing e comunicação com clientes
- Suporte para múltiplos usuários com diferentes níveis de acesso
- Funcionalidades avançadas de análise de dados e inteligência artificial

## 5. Usuários do Sistema
Resposta:

Os usuários do sistema serão o empresário e os funcionários do negócio, que terão acesso para cadastrar, consultar e gerenciar as informações dos clientes.

## 6. Limitações do Projeto
Resposta:

- O sistema será desenvolvido para uso em um ambiente local, sem suporte para acesso remoto ou em nuvem.
- O sistema não terá funcionalidades avançadas de segurança, como autenticação de múltiplos fatores ou criptografia de dados.
- O sistema será desenvolvido com uma interface simples, sem suporte para dispositivos móveis ou responsividade.

## 7. Entregas do Projeto
Resposta:

As entregas do projeto incluirão:
- Documento Incial do Projeto com Levantamento de Requisitos
- Desenvolvimento do sistema de Cadastro de Clientes
- Testes e validação do sistema
- Documentação do usuário e do sistema

| ID   | Requisito           | Descrição                                                                                                     |

| RF05 | Excluir Cliente     | O sistema deve permitir a exclusão de clientes do cadastro.                                                   |
